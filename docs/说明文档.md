# LBM-IBM-FSI 项目说明文档

## 一、项目概述

本项目实现了一个高性能的**格子 Boltzmann 法（LBM）+ 浸入边界法（IBM）+ 流固耦合（FSI）**仿真框架，采用多语言混合架构，在性能、安全性和可扩展性之间取得平衡。

---

## 四、实现思路

### 4.1 设计原则

本框架遵循以下核心设计原则：

1. **各层只做最擅长的事**：计算密集型内核用 C++ 实现；安全驱动层用 Rust；科学计算与可视化用 Python。
2. **零拷贝或最小拷贝数据传输**：
   - Rust ↔ C++ 之间通过裸指针（C ABI）直接操作同一块堆内存；
   - Rust → Python 之间通过 pyo3 以 Python `list` 传递数组，避免写入中间文件。
3. **输出频率与开销匹配**：
   - 高频（每步或每数百步）：Rust 原生写出 NPZ 快照或 CSV 行，开销极低；
   - 低频（每数千步）：调用 Python 生成高质量云图，开销较高但频率低。
4. **Python 独立可用**：所有 Python 模块可在不启动 Rust 程序的情况下独立运行，适合离线后处理和脚本化工作流。

### 4.2 两种 Python 调用模式

| 模式 | 触发方式 | 数据传递 | 适用场景 |
|------|----------|----------|----------|
| **子进程模式** | `pre_script` / `post_script` TOML 配置 | 通过文件（TOML、NPZ） | 重量级预处理、完整后处理流水线 |
| **FFI 模式** | `python-ffi` Cargo 特性 + `plot_interval` | 直接内存传递（无文件） | 低频云图、实时诊断 |

两种模式互不排斥，可以同时启用。

## 五、模块间调用关系

### 5.1 完整仿真流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                         完整仿真流程                                 │
│                                                                     │
│  ① 可选：Python 子进程预处理                                         │
│     lbm_pre.config_gen  → 生成 configs/*.toml                       │
│     lbm_pre.mesh        → 生成 domain.msh                           │
│     通过命令行参数传递配置文件路径                                    │
│                          ↓                                          │
│  ② Rust 主控（orchestrator/src/main.rs）                             │
│     读取 configs/*.toml                                              │
│     [可选] Python FFI：调用 lbm_pre.bridge.geometry_markers_raw()    │
│       → 直接获取标记点坐标（无 CSV 文件）                             │
│     调用 C++ 核心（FFI）运行 LBM 仿真循环                             │
│       每隔 write_interval 步 → NPZ 快照（Rust 原生写出）              │
│       每步（可选）           → CSV 一行（Rust 原生追加）               │
│       每隔 plot_interval 步  → Python FFI 云图（无 NPZ 中间文件）     │
│                          ↓                                          │
│  ③ 可选：Python 子进程后处理                                         │
│     lbm_post.vtk_reader → 读取 output/fluid_*.npz                   │
│     lbm_post.plot       → 生成 PNG 图像                              │
│     lbm_post.analysis   → 计算阻力/升力、体积平均量等                 │
└─────────────────────────────────────────────────────────────────────┘
```

### 5.2 Rust ↔ C++ 调用（FFI）

`bindings/src/lib.rs` 通过 C ABI 调用 C++ 核心库：

```
Rust orchestrator
    │
    ├─ LbmGrid::new(nx, ny, nz, model)
    │       └─→ C ABI: lbm_grid_new()  →  C++ LatticeGrid（堆分配）
    │
    ├─ LbmSolver::new(&mut grid, omega, cm)
    │       └─→ C ABI: lbm_solver_new() → C++ Solver（堆分配）
    │
    ├─ solver.step(&mut grid)             ← 每个时间步执行碰撞+迁移
    │       └─→ C ABI: lbm_solver_step()
    │
    └─ grid.rho(idx) / .ux(idx) / .uy(idx)
            └─→ C ABI: lbm_grid_rho/ux/uy() ← 读取格点流场数据
```

`bindings/build.rs` 在 Rust 编译期自动调用 cmake 构建 `liblbm_core.a`，并通过 `cargo:rustc-link-lib=static=lbm_core` 链接。

### 5.3 Rust → Python 子进程调用

Rust 主控使用 `std::process::Command` 以子进程方式调用 Python 脚本：

```
main() 主控
    │
    ├─ [可选] 预处理阶段
    │   run_python_subprocess(interpreter, pre_script, [config_path])
    │       └─→ python3 <pre_script> configs/my_run.toml
    │
    ├─ [仿真循环]
    │
    └─ [可选] 后处理阶段
        run_python_subprocess(interpreter, post_script, [output_dir])
            └─→ python3 <post_script> output/lid_cavity
```

**接口规范**：
- 预处理脚本接收一个位置参数：TOML 配置文件路径。
- 后处理脚本接收一个位置参数：输出目录路径。
- 脚本退出码非 0 时，Rust 主程序报错退出。

### 5.4 Rust → Python FFI 调用（pyo3）

启用 `python-ffi` Cargo 特性后，Rust 通过 pyo3 在进程内直接调用 Python：

```
main() [需要 --features python-ffi]
    │
    ├─ python_bridge::add_python_path("python/")
    │       └─→ pyo3: sys.path.insert(0, "python/")
    │
    ├─ python_bridge::markers_from_geometry("circle", 50.0, 40.0, 10.0, 64)
    │       └─→ pyo3: lbm_pre.bridge.geometry_markers_raw("circle", ...)
    │               → 返回 (Vec<f64>, Vec<f64>, Vec<f64>)  ← 无文件
    │
    └─ python_bridge::plot_field(&rho, &ux, &uy, nx, ny, step, time,
                                  out_dir, "velocity_magnitude")
            └─→ pyo3: lbm_post.bridge.plot_field_raw(rho_list, ux_list, uy_list, ...)
                    → numpy reshape → matplotlib 绘图 → 保存 PNG  ← 无 NPZ 中间文件
```

**数据传递方式**：Rust `&[f64]` 切片 → `pyo3::types::PyList` → Python 函数参数。NumPy 在 Python 侧负责 reshape（`np.asarray(rho).reshape(ny, nx)`），Rust 侧无需了解 NumPy 内部格式。

### 5.5 Python 独立使用路径（无 Rust）

Python 模块设计为可独立运行，无需 Rust 程序：

```
用户 Python 脚本
    │
    ├─ from lbm_pre.config_gen import SolverConfig
    │   SolverConfig.lid_driven_cavity().write("configs/my.toml")
    │
    ├─ from lbm_pre.geometry import circle_markers, write_markers_csv
    │   markers = circle_markers(50, 40, 10, 128)
    │   write_markers_csv(markers, "markers.csv")     ← 生成文件
    │
    ├─ from lbm_pre.bridge import geometry_markers_raw
    │   x, y, ds = geometry_markers_raw("circle", 50, 40, 10, 128)  ← 无文件
    │
    ├─ from lbm_post.vtk_reader import NpzReader
    │   snap = NpzReader("output/").last()
    │
    ├─ from lbm_post.plot import plot_velocity_magnitude, save_figure
    │   fig, _ = plot_velocity_magnitude(snap)
    │   save_figure(fig, "vel_mag.png")
    │
    └─ from lbm_post.bridge import plot_field_raw
        plot_field_raw(rho, ux, uy, nx, ny, step, time, "output/", "vorticity")
```

## 六、数据传输格式要求

### 6.1 TOML 配置文件（Python → Rust）

Python 端用 `lbm_pre.config_gen.SolverConfig.write()` 生成，Rust 端用 `Config::from_file()` 解析。

完整结构：

```toml
[simulation]
n_steps        = 10000          # 总时间步数
dt             = 1.0            # 时间步长（格子单位）
lattice_model  = "D2Q9"         # "D2Q9" | "D3Q19" | "D3Q27"
collision_model = "MRT"         # "BGK" | "MRT"

[fluid]
nx   = 100                      # x 方向格点数
ny   = 100                      # y 方向格点数
nz   = 1                        # z 方向格点数（2D 仿真设 1）
nu   = 0.01                     # 运动粘度（格子单位，建议 0.05 ~ 0.5）
rho0 = 1.0                      # 初始均匀密度

  [[fluid.boundary_conditions]]
  bc_type = "zou_he_velocity"   # "bounce_back" | "zou_he_velocity" | "zou_he_pressure"
  face    = "north"             # "west" | "east" | "south" | "north" | "bottom" | "top"
  ux      = 0.1                 # 边界 x 速度（jou_he_velocity 有效）
  uy      = 0.0
  rho     = 1.0                 # 边界密度（zou_he_pressure 有效）

[structure]                     # 可选，FSI 结构参数
young_modulus  = 1.0e3
second_moment  = 1.0e-6
density        = 1.5
area           = 0.01
length         = 0.3
n_elements     = 10

[ibm]                           # 可选，IBM 几何参数
geometry   = "circle"           # "circle" | "filament"
x0         = 50.0               # 圆心/起点 x（格子单位）
y0         = 40.0               # 圆心/起点 y
size       = 10.0               # 半径（circle）/ 长度（filament）
n_markers  = 64                 # 拉格朗日标记点数
delta_kernel = "four_point"     # "two_point" | "four_point"

[output]
write_interval     = 500        # NPZ 快照输出间隔（高频原生写出）
directory          = "output/lid_cavity"
plot_interval      = 2000       # Python FFI 云图间隔（可选，低频）
enable_csv_monitor = true       # 每步追加 CSV 一行（轻量时序输出）

[python]                        # 可选
interpreter = "python3"         # Python 可执行文件路径
pre_script  = "scripts/pre.py"  # 预处理脚本（子进程模式，可省略）
post_script = "scripts/post.py" # 后处理脚本（子进程模式，可省略）
pythonpath  = "python"          # 追加到 sys.path，使 lbm_pre/lbm_post 可导入
```

#### 参数约束

| 参数 | 类型 | 约束 |
|------|------|------|
| `nu` | float64 | 建议 0.05 ≤ ν ≤ 0.5（保证 τ ∈ (0.5, 2)） |
| `n_steps` | uint64 | ≥ 0 |
| `write_interval` | uint64 | ≥ 1 |
| `lattice_model` | string | "D2Q9" / "D3Q19" / "D3Q27" |
| `collision_model` | string | "BGK" / "MRT" |

### 6.2 NPZ 快照文件（Rust → Python）

Rust `output::write_snapshot_npz()` 每隔 `write_interval` 步写出。  
Python `lbm_post.vtk_reader.NpzReader` 读取。

文件名：`<output_dir>/fluid_<NNNNNN>.npz`  
格式：NumPy `.npz`（ZIP 压缩包，内含 `.npy` 文件）

| 数组键 | 形状 | 类型 | 说明 |
|--------|------|------|------|
| `rho` | `(ny, nx)` | float64 | 密度场，行主序 `[j, i]` 对应格点 `(i, j)` |
| `ux`  | `(ny, nx)` | float64 | x 方向速度场 |
| `uy`  | `(ny, nx)` | float64 | y 方向速度场 |
| `step` | 标量 | int64 | 时间步索引 |
| `time` | 标量 | float64 | 物理时间（= step × dt） |

**Python 读取示例：**
```python
from lbm_post.vtk_reader import NpzReader
snap = NpzReader("output/lid_cavity").last()
print(snap.rho.shape)    # (100, 100)
```

### 6.3 CSV 监控日志（Rust 写出，供任意工具读取）

当 `enable_csv_monitor = true` 时，Rust `output::append_monitor_csv()` 每步追加一行。

文件名：`<output_dir>/monitor.csv`

格式（CSV，无二进制依赖）：

```csv
step,time,ke
1,1.000000,5.1234567890e-4
2,2.000000,5.1234567890e-4
...
```

| 列 | 类型 | 说明 |
|----|------|------|
| `step` | int | 时间步索引 |
| `time` | float | 物理时间 |
| `ke` | float | 体积平均动能 0.5·mean(ux²+uy²) |

**适用场景**：高频时序监控（每步记录），文件极小，可直接用 Excel/Python/gnuplot 打开。

### 6.4 Python FFI 直接传递（pyo3，无中间文件）

#### 网格标记（Rust 接收来自 Python 的数据）

调用 `python_bridge::markers_from_geometry()` → `lbm_pre.bridge.geometry_markers_raw()`：

```
Rust 调用参数：(geometry: &str, x0, y0, size, n_markers)
Python 返回值：(x: list[float], y: list[float], ds: list[float])
Rust 接收类型：(Vec<f64>, Vec<f64>, Vec<f64>)
```

#### 云图绘制（Rust 发送数据给 Python）

调用 `python_bridge::plot_field()` → `lbm_post.bridge.plot_field_raw()`：

```
Rust 发送数据：
  rho: &[f64]   → PyList<f64>  (len = nx * ny，行主序)
  ux:  &[f64]   → PyList<f64>
  uy:  &[f64]   → PyList<f64>
  nx, ny: usize → int
  step: u64     → int
  time: f64     → float
  out_dir: &str → str
  field: &str   → str  ("velocity_magnitude" | "vorticity" | "pressure" | "streamlines")

Python 处理：np.asarray(rho).reshape(ny, nx) → FieldSnapshot → matplotlib → PNG
```

### 6.5 CSV 标记文件（Python 独立模式，可选）

当 Python 独立运行时，`lbm_pre.geometry.write_markers_csv()` 可将标记点写为 CSV：

```csv
# tag: circle
x,y,ds
50.0,60.0,0.9817477
...
```

| 列 | 类型 | 说明 |
|----|------|------|
| `x` | float | 标记点 x 坐标（格子单位） |
| `y` | float | 标记点 y 坐标（格子单位） |
| `ds` | float | 对应弧长元素（用于 IBM 积分） |

## 七、输出策略对比

| 策略 | 频率 | 数据量 | 实现 | 适用场景 |
|------|------|--------|------|----------|
| NPZ 快照 | 低（每数百/千步） | 全场（ny×nx×3×8 B） | Rust 原生（`output.rs`） | 全场数据存档，供离线后处理 |
| CSV 监控 | 高（每步） | 极小（1 行 ≈ 100 B） | Rust 原生追加 | 时序监控、收敛判断 |
| Python FFI 云图 | 最低（每数千步） | 无（直接生成 PNG） | pyo3 → matplotlib | 运行时可视化诊断 |
| Python 子进程 | 仅开始/结束 | 通过文件 | subprocess | 重量级预/后处理流水线 |

## 八、构建与运行

### 8.1 前置条件

- CMake ≥ 3.20
- C++17 编译器（GCC ≥ 11 或 Clang ≥ 14）
- MPI 实现（OpenMPI ≥ 4.0 或 MPICH ≥ 3.4）
- Rust 工具链 ≥ 1.70（`rustup`）
- Python ≥ 3.11 + pip
- （仅 `python-ffi` 特性）Python 开发头文件（`python3-dev`）

### 8.2 安装 Python 依赖

```bash
cd python
pip install -e ".[test]"    # 安装 numpy, matplotlib, scipy, pytest, gmsh
```

### 8.3 构建

```bash
# 标准构建（无 Python FFI）
cargo build --release

# 启用 Python FFI 构建（需要 python3-dev）
cargo build --release --features python-ffi
```

### 8.4 运行

```bash
# 基本运行（标准配置）
./target/release/lbm-ibm-fsi --config configs/lid_driven_cavity.toml

# 覆盖时间步数（快速测试）
./target/release/lbm-ibm-fsi --config configs/lid_driven_cavity.toml --steps 100

# 启用 Python FFI 云图（需要 python-ffi 特性构建）
# 在 TOML 中配置 [output] plot_interval = 1000 及 [python] pythonpath = "python"
./target/release/lbm-ibm-fsi --config configs/my_run.toml

# MPI 多进程
mpirun -n 4 ./target/release/lbm-ibm-fsi --config configs/lid_driven_cavity.toml
```

### 8.5 独立运行 Python 端到端示例

```bash
cd python
PYTHONPATH=. python3 examples/lid_driven_cavity.py
```

## 十、扩展指南

### 10.1 添加新的 Python FFI 函数

1. 在 `python/lbm_pre/bridge.py` 或 `python/lbm_post/bridge.py` 中添加接受 `list[float]` 参数的函数；
2. 在 `orchestrator/src/python_bridge.rs` 中添加对应的 Rust 函数（使用 `#[cfg(feature = "python-ffi")]` 保护）；
