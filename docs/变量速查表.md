## 1. C++ 格子常量（D2Q9 / D3Q19）

|------|------|------|

| `C[a][d]` | `array<array<int,2>, 9>` | 第 a 方向的速度向量分量（d=0:x, d=1:y）；a=0 静止，a=1~8 为 E/N/W/S/NE/NW/SW/SE |

|------|------|------|
| `Q` | `constexpr int = 19` | D3Q19 离散速度方向数 |

## 2. C++ LatticeGrid 字段

> 结构体：`lbm::LatticeGrid`（`core/include/lbm/lattice.hpp`）
> 作用：保存所有格子节点的分布函数及宏观量，是 LBM 求解的核心数据容器。

| 字段 | 类型 | 含义 |
|------|------|------|
| `nx` | `int` | X 方向格点数（含幽灵列，若 MPI 分解） |
| `ny` | `int` | Y 方向格点数（含幽灵行，若 MPI 分解） |
| `nz` | `int` | Z 方向格点数（二维算例固定为 1） |
| `q` | `int` | 离散速度方向数（D2Q9=9, D3Q19=19, D3Q27=27） |
| `model` | `LatticeModel` | 格子模型枚举（D2Q9 / D3Q19 / D3Q27） |
| `f[n·Q + a]` | `vector<double>` | 分布函数；n=节点平坦索引，a=速度方向编号 |
| `f_tmp[n·Q + a]` | `vector<double>` | 碰撞后（post-collision）临时缓冲；流式迁移完成后与 f 交换 |
| `rho[n]` | `vector<double>` | 宏观密度 ρ；由 `compute_macroscopic()` 更新 |
| `u[n·dim + d]` | `vector<double>` | 宏观速度 u；dim=2(2D)/3(3D)，d=0:ux, 1:uy, 2:uz |
| `force[n·dim + d]` | `vector<double>` | 体力密度（Guo 格式使用）；未设置时为全零 |
| `solid[n]` | `vector<uint8_t>` | 固体标记：1=固体节点，0=流体节点 |
| `q_ibb[n·Q + a]` | `vector<float>` | IBB 壁面距离分数 q（0 < q ≤ 1）；q=0.5 为标准 halfway BB；由 `mark_solid_cylinder()` 填充 |

### 成员函数

| 函数 | 返回值 | 含义 |
|------|--------|------|
| `size()` | `int` | 节点总数 = nx × ny × nz |
| `idx(i, j, k=0)` | `int` | 平坦节点索引 = i + nx·(j + ny·k) |
| `dim()` | `int` | 空间维度（D2Q9→2, 其他→3） |
| `compute_macroscopic()` | `void` | 由分布函数更新 rho 和 u |

## 3. C++ Solver 字段

> 类：`lbm::Solver`（`core/include/lbm/solver.hpp`）
> 作用：封装 LBM 碰撞-流式迁移时间推进逻辑。

| 成员 | 类型 | 含义 |
|------|------|------|
| `grid_` | `LatticeGrid&` | 绑定的格子网格（引用，外部持有） |
| `omega_` | `double` | 松弛频率 ω = 1/τ；与运动粘度关系：ν = cs²(1/ω − 0.5)dt，cs²=1/3 |
| `cm_` | `CollisionModel` | 碰撞模型（BGK 或 MRT） |
| `bcs_` | `vector<BoundaryCondition>` | 每步流式迁移后自动施加的边界条件列表 |
| `mpi_decomp_` | `const MpiDecomp*` | 绑定的 1D Y 向 MPI 分解（nullptr=未绑定） |
| `mpi_decomp2d_` | `const MpiDecomp2D*` | 绑定的 2D XY 块 MPI 分解（nullptr=未绑定） |
| `mpi_decomp3d_` | `const MpiDecomp3D*` | 绑定的 3D XYZ 块 MPI 分解（nullptr=未绑定） |
| `solid_bc_type_` | `SolidBCType` | 固体节点反弹方案（None / BounceBack / InterpolatedBounceBack） |

### CollideGuard 辅助结构（幽灵层跳过控制）

| 字段 | 含义 |
|------|------|
| `n_start` | 碰撞循环起始节点索引（跳过南幽灵行）；MPI 模式下 = nx |
| `n_end` | 碰撞循环终止节点索引（跳过北幽灵行）；MPI 模式下 = n−nx |
| `use_mpi2d` | 是否使用二维 MPI 分解的幽灵跳过逻辑 |
| `gnx2d / gny2d` | 本地网格含幽灵层的 nx / ny（2D 模式） |
| `sg2d / ng2d / wg2d / eg2d` | 南/北/西/东幽灵层存在标志（2D） |
| `use_mpi3d` | 是否使用三维 MPI 分解的幽灵跳过逻辑 |
| `gnx3d/gny3d/gnz3d` | 本地网格含幽灵层的 nx/ny/nz（3D 模式） |
| `sg3d/ng3d/wg3d/eg3d/bg3d/tg3d` | 南/北/西/东/底/顶幽灵层存在标志（3D） |

## 4. C++ 边界条件

### 4.1 `lbm::BCType` 枚举

| 枚举值 | 含义 |
|--------|------|
| `BounceBack` | 半步长反弹；壁面在节点间半格处；2 阶精度；无滑移固壁标准选择 |
| `BounceBackFullWay` | 全步长反弹；壁面在节点处；1 阶精度；简单快速 |
| `ZouHe_Velocity` | Zou-He 速度入口/出口；规定 ux/uy/uz，由动量守恒确定未知 f |
| `ZouHe_Pressure` | Zou-He 压力入口/出口；规定 rho（= p/cs²），外推速度 |
| `FullyDeveloped` | 充分发展出口；将出口 f 替换为上游一层的值（零法向梯度） |
| `FreeOutlet` | 自由出口；与 `FullyDeveloped` 等价 |
| `Guo_Extrapolation` | 郭照立非平衡外推；rho>0 为压力模式，rho=0 为速度模式 |
| `Periodic` | 周期边界；仅记录用，实际在流式迁移中隐式实现 |

### 4.2 `lbm::Face` 枚举

| 枚举值 | 含义 |
|--------|------|
| `West` | x=0 边界（左/进口壁） |
| `East` | x=nx-1 边界（右/出口壁） |
| `South` | y=0 边界（底壁） |
| `North` | y=ny-1 边界（顶壁） |
| `Bottom` | z=0 边界（三维算例，前壁） |
| `Top` | z=nz-1 边界（三维算例，后壁） |

### 4.3 `lbm::BoundaryCondition` 结构体

| 字段 | 类型 | 含义 |
|------|------|------|
| `type` | `BCType` | 边界条件类型 |
| `face` | `Face` | 应用于哪个面 |
| `ux` | `double` | X 方向规定速度（ZouHe_Velocity / Guo 速度模式） |
| `uy` | `double` | Y 方向规定速度 |
| `uz` | `double` | Z 方向规定速度 |
| `rho` | `double` | 规定密度（ZouHe_Pressure；Guo 压力模式 rho>0；Guo 速度模式 rho=0） |

### 4.4 `lbm::PhysicalBounds` 结构体（MPI 物理边界范围）

| 字段 | 类型 | 含义 |
|------|------|------|
| `j_s` | `int` | 物理南边界行索引（本地坐标，含）；非 MPI=0，1D MPI=1 |
| `j_n` | `int` | 物理北边界行索引（本地坐标，含）；非 MPI=ny-1，1D MPI=ny-2 |
| `i_w` | `int` | 物理西边界列索引（本地坐标，含）；非 MPI/1D=0 |
| `i_e` | `int` | 物理东边界列索引（本地坐标，含）；非 MPI/1D=nx-1 |
| `has_south_wall` | `bool` | 本进程是否拥有全局南物理壁（false→跳过 South BC） |
| `has_north_wall` | `bool` | 本进程是否拥有全局北物理壁 |
| `has_west_wall` | `bool` | 本进程是否拥有全局西物理壁 |
| `has_east_wall` | `bool` | 本进程是否拥有全局东物理壁 |

## 5. C++ MPI 域分解

### 5.1 `lbm::MpiDecomp`（旧，1D Y 向，向后兼容）

| 字段 | 含义 |
|------|------|
| `rank` | 当前进程编号（0 ~ nprocs-1） |
| `nprocs` | 进程总数 |
| `global_nx` | 全局 X 节点数 |
| `global_ny` | 全局 Y 节点数 |
| `y_start` | 本地物理起始行（全局坐标） |
| `y_end` | 本地物理结束行（全局坐标，含） |
| `local_ny` | 本地物理行数（不含 2 条幽灵行） |
| `rank_south` | 南邻进程 rank；-1=无邻居（MPI_PROC_NULL） |
| `rank_north` | 北邻进程 rank；-1=无邻居 |
| `grid_ny()` | 本地网格含幽灵的 ny；nprocs>1 时 = local_ny+2 |

### 5.2 `lbm::MpiDecomp2D`（主推，XY 块分解）

| 字段 | 含义 |
|------|------|
| `rank` | 当前进程全局编号 |
| `nprocs` | 进程总数（= px × py） |
| `px` | X 方向进程数 |
| `py` | Y 方向进程数 |
| `col_rank` | X 方向进程坐标（0..px-1） |
| `row_rank` | Y 方向进程坐标（0..py-1） |
| `global_nx / global_ny` | 全局 X / Y 节点数 |
| `x_start / x_end` | 本地物理列范围（全局坐标，含端点） |
| `y_start / y_end` | 本地物理行范围（全局坐标，含端点） |
| `local_nx / local_ny` | 本地物理列数 / 行数（不含幽灵） |
| `rank_south/north/west/east` | 四邻进程 rank；-1=无邻居 |
| `grid_nx() / grid_ny()` | 本地含幽灵的 nx / ny |
| `phys_x0() / phys_y0()` | 物理区域在本地网格中的 X / Y 偏移（0 或 1） |
| `has_south/north/west/east_ghost()` | 幽灵层存在查询 |
| `has_south/north/west/east_wall()` | 全局物理壁查询 |

### 5.3 `lbm::MpiDecomp3D`（3D XYZ 块分解，预留）

| 字段 | 含义 |
|------|------|
| `rank / nprocs` | 进程编号 / 总数 |
| `px / py / pz` | X / Y / Z 方向进程数 |
| `col_rank / row_rank / pz_rank` | X / Y / Z 方向进程坐标 |
| `global_nx / global_ny / global_nz` | 全局三维节点数 |
| `x_start,x_end / y_start,y_end / z_start,z_end` | 本地物理三维范围 |
| `local_nx / local_ny / local_nz` | 本地物理尺寸（不含幽灵） |
| `rank_west/east/south/north/bottom/top` | 六邻进程 rank |
| `grid_nx/ny/nz()` | 含幽灵的本地尺寸 |
| `phys_x0/y0/z0()` | 物理区域偏移（0 或 1） |

## 10. Rust TOML 配置结构体

### 10.1 `Config`（顶层）

### 10.2 `SimulationConfig`

| 字段 | 类型 | 含义 |
|------|------|------|
| `n_steps` | `u64` | 总时间步数 |
| `dt` | `f64` | 时间步长（格子单位，通常为 1.0） |
| `lattice_model` | `String` | 格子模型："D2Q9"/"D3Q19"/"D3Q27" |

## 12. 快速换算公式

| 公式 | 说明 |
|------|------|
| `ω = 1 / (3·ν + 0.5)` | 运动粘度 ν → 松弛频率 ω（格子单位，dt=dx=1） |
| `ν = cs²(1/ω − 0.5)` | 松弛频率 ω → 运动粘度 ν（cs²=1/3） |
| `Re = U·L / ν` | 雷诺数（U=入口速度，L=特征长度，均为格子单位） |
| `Ma = U / cs = U·√3` | 马赫数（cs=1/√3≈0.577；Ma < 0.1 时可压缩误差可忽略） |
| `idx(i,j) = i + nx·j` | 2D 节点平坦索引（j 为行，i 为列） |
| `idx(i,j,k) = i + nx·(j + ny·k)` | 3D 节点平坦索引 |
| `f[n·Q + a]` | 节点 n、方向 a 的分布函数存储位置 |
| `u[n·dim + d]` | 节点 n、分量 d 的速度存储位置（d=0:x, 1:y, 2:z） |
| `q_ibb[n·Q + a]` | 节点 n、方向 a 的 IBB 壁面距离分数 q（0<q≤1） |
