## 1. 参数读取与配置解析

**源文件：** `orchestrator/src/config.rs`、`configs/lid_driven_cavity.toml`

### 1.1 命令行入口

程序通过 `clap` 库解析命令行参数：

```
./target/release/lbm-ibm-fsi --config configs/lid_driven_cavity.toml [--steps N]
```

- `--config`（默认 `configs/lid_driven_cavity.toml`）：指定 TOML 配置文件路径。
- `--steps`：可选覆盖，用于临时减少仿真步数（调试用），不修改配置文件。

### 1.2 TOML 配置文件结构

配置文件分为以下顶层段落：

| TOML 段落 | 对应 Rust 结构体 | 说明 |
|-----------|----------------|------|
| `[simulation]` | `SimulationConfig` | 总步数、时间步长、格子模型、碰撞模型 |
| `[fluid]` | `FluidConfig` | 网格尺寸（nx/ny/nz）、运动粘度 ν、初始密度 ρ₀、边界条件列表 |
| `[structure]` | `StructureConfig`（可选）| 梁的材料参数：E、I、ρₛ、A、L、单元数 |
| `[ibm]` | `IbmConfig`（可选）| 几何类型（圆形/丝状体）、位置、尺寸、标记点数、δ 函数核类型 |
| `[output]` | `OutputConfig` | 快照写出间隔、输出目录、绘图间隔、CSV 监控开关 |
| `[python]` | `PythonConfig` | Python 解释器路径、预/后处理脚本、额外 sys.path |
| `[plugins]` | `PluginsConfig` | 四个插件扩展点的名称（空字符串 = 不使用） |

**lid_driven_cavity.toml 示例摘录：**

```toml
[simulation]
n_steps        = 10000
dt             = 1.0
lattice_model  = "D2Q9"
collision_model = "MRT"

[fluid]
nx = 100
ny = 100
nu = 0.01          # 运动粘度（格子单位）
rho0 = 1.0

  [[fluid.boundary_conditions]]
  bc_type = "zou_he_velocity"
  face    = "north"
  ux      = 0.1    # 盖板速度
```

### 1.3 松弛频率计算

从粘度 ν 自动推导 LBM 松弛频率 ω：

$$\tau = 3\nu + \frac{1}{2}, \quad \omega = \frac{1}{\tau}$$

实现在 `Config::omega()` 方法中：

```rust
pub fn omega(&self) -> f64 {
    1.0 / (3.0 * self.fluid.nu + 0.5)
}
```

对于 `nu = 0.01`，得到 `ω ≈ 1.961`，对应雷诺数 Re = U·L/ν = 0.1 × 100 / 0.01 = 100。

## 2. 网格构建与数据结构

**源文件：** `core/include/lbm/lattice.hpp`、`core/src/lbm/lattice.cpp`

### 2.1 LatticeGrid 结构体

欧拉格子网格由 `lbm::LatticeGrid` 表示，其核心字段如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| `nx`, `ny`, `nz` | `int` | 各方向格子数（二维时 nz=1） |
| `q` | `int` | 离散速度方向数（D2Q9: 9；D3Q19: 19） |
| `f` | `vector<double>` | 分布函数，大小 n×q，按 `[节点索引 * q + 方向]` 展开 |
| `f_tmp` | `vector<double>` | 流式迁移临时缓冲区，大小同 f |
| `rho` | `vector<double>` | 宏观密度场，大小 n |
| `u` | `vector<double>` | 宏观速度场，大小 n×dim，按 `[节点索引 * dim + 分量]` 存储 |
| `force` | `vector<double>` | 体力密度（IBM 力），大小 n×dim |

**节点索引约定（行主序）：**

$$\text{idx}(i, j, k) = i + n_x \cdot (j + n_y \cdot k)$$

### 2.2 D2Q9 格子常量

D2Q9 是本项目二维仿真的标准格子模型，所有常量在编译期以 `constexpr` 定义：

**9 个离散速度向量** $\mathbf{c}_\alpha$（$\alpha = 0, \ldots, 8$）：

| 方向 α | cx | cy | 描述 |
|--------|----|----|------|
| 0 | 0 | 0 | 静止 |
| 1 | 1 | 0 | 东（E） |
| 2 | 0 | 1 | 北（N） |
| 3 | -1 | 0 | 西（W） |
| 4 | 0 | -1 | 南（S） |
| 5 | 1 | 1 | 东北（NE） |
| 6 | -1 | 1 | 西北（NW） |
| 7 | -1 | -1 | 西南（SW） |
| 8 | 1 | -1 | 东南（SE） |

**格子权重** $w_\alpha$：

$$w_0 = \frac{4}{9}, \quad w_{1,2,3,4} = \frac{1}{9}, \quad w_{5,6,7,8} = \frac{1}{36}$$

**反方向表** `OPP`：`{0, 3, 4, 1, 2, 7, 8, 5, 6}`（用于反弹边界条件）。

**格子声速平方：** $c_s^2 = 1/3$（格子单位）。

### 2.3 内存分配

`LatticeGrid` 构造函数初始化：

- `f` → 全零（随后由 `Solver` 构造函数覆盖为平衡值）
- `f_tmp` → 全零（流式迁移缓冲区，每步被覆盖）
- `rho` → 全 1.0（均匀初始密度 ρ₀ = 1）
- `u` → 全 0.0（初始静止流场）
- `force` → 全 0.0（初始无体力）

## 3. 初始条件赋值

**源文件：** `core/src/lbm/solver.cpp`（`Solver` 构造函数）

### 3.1 平衡分布函数初始化

在 `lbm::Solver` 构造时，将所有节点的分布函数初始化为对应静止平衡态（ρ = 1，u = 0）：

$$f_\alpha^{(0)}(\mathbf{x}) = f_\alpha^{eq}(\rho_0, \mathbf{0}) = w_\alpha \rho_0$$

这是因为当 u = 0 时，平衡分布函数退化为：

$$f_\alpha^{eq} = w_\alpha \rho \left[1 + \frac{\mathbf{c}_\alpha \cdot \mathbf{u}}{c_s^2} + \frac{(\mathbf{c}_\alpha \cdot \mathbf{u})^2}{2c_s^4} - \frac{|\mathbf{u}|^2}{2c_s^2}\right] = w_\alpha \rho$$

### 3.2 平衡分布函数的一般形式

Maxwell-Boltzmann 平衡分布（二阶截断展开）在 `lbm::f_eq()` 中实现：

$$f_\alpha^{eq}(\rho, \mathbf{u}) = w_\alpha \rho \left(1 + \frac{\mathbf{c}_\alpha \cdot \mathbf{u}}{c_s^2} + \frac{(\mathbf{c}_\alpha \cdot \mathbf{u})^2}{2c_s^4} - \frac{|\mathbf{u}|^2}{2c_s^2}\right)$$

其中 $c_s^2 = 1/3$。代入 D2Q9 各方向的 $\mathbf{c}_\alpha$，可以得到与速度二阶精度的近似平衡态。

## 4. 主仿真循环概述

**源文件：** `orchestrator/src/main.rs`

主仿真循环（`for step in 0..cfg.simulation.n_steps`）按照如下顺序执行：

```
每一个时间步 n：
  ├─ 1. [运动插件] 更新固体/标记点位置（若注册）
  ├─ 2. [C++ 求解器] LBM 碰撞步骤
  ├─ 3. [C++ 求解器] LBM 流式迁移步骤 + 宏观量更新
  ├─ 4. [C++ 边界] 应用边界条件（反弹 / Zou-He）
  ├─ 5. [网格插件] 自适应网格（若注册）
  ├─ 6. [FSI 插件] 柔性体推进（若注册）
  ├─ 7. [Rust 输出] 每 write_interval 步写出 NPZ 快照
  └─ 8. [Rust 输出] 每步追加 CSV 监控（若启用）
```

在 Rust 侧，通过 FFI 调用 `lbm_solver_step_n()`，该函数在 C++ 侧按上述顺序执行步骤 1-6。

## 5. 碰撞步骤

**源文件：** `core/src/lbm/solver.cpp`（`collide_bgk()`、`collide_mrt()`）

碰撞步骤在**原地**修改分布函数，将 f 向平衡态松弛，物理上模拟粒子间的碰撞弛豫过程。

### 5.1 BGK 单松弛时间算子

BGK（Bhatnagar-Gross-Krook）是最简单的碰撞算子：

$$f_\alpha^*(\mathbf{x}, t) = f_\alpha(\mathbf{x}, t) - \omega \left[f_\alpha(\mathbf{x}, t) - f_\alpha^{eq}(\rho, \mathbf{u})\right]$$

- $\omega = 1/\tau$ 为松弛频率，$\tau$ 为无量纲松弛时间。
- 当 $\omega = 1$（即 $\tau = 1$）时，一步完全松弛到平衡态。
- 运动粘度由 $\nu = c_s^2(\tau - 1/2) = \frac{1}{3}\left(\frac{1}{\omega} - \frac{1}{2}\right)$ 给出。

**实现要点：**
- 碰撞前需先通过 `compute_macroscopic()` 得到当前宏观量 ρ 和 u。
- 采用 `#pragma omp parallel for` 并行化（启用 `LBM_ENABLE_OPENMP` 时）。
- 每个节点的计算相互独立，数据并行效率高。

**BGK 的局限性：** 单一 ω 控制所有矩的松弛，在低粘度（高 Re）时数值稳定性差，且剪切粘度与体积粘度无法独立设置。

### 5.2 MRT 多松弛时间算子

MRT（Multiple Relaxation Time）在**矩空间**中以不同松弛率分别对各阶矩进行松弛，有效提升低粘度仿真的稳定性，是本项目 `lid_driven_cavity.toml` 中的默认碰撞模型。

**MRT 的三步流程（D2Q9）：**

**第一步：投影到矩空间**

$$\mathbf{m} = \mathbf{M} \mathbf{f}$$

变换矩阵 $\mathbf{M}$（9×9）将分布函数向量 $\mathbf{f}$ 投影为矩向量 $\mathbf{m}$：

$$\mathbf{m} = [\rho, e, \varepsilon, j_x, q_x, j_y, q_y, p_{xx}, p_{xy}]^T$$

- $\rho$：密度（0 阶矩）
- $e$：能量（与 $p_{xx}$、$p_{xy}$ 相关）
- $j_x, j_y$：动量分量（1 阶矩）
- $p_{xx}, p_{xy}$：应力张量分量（2 阶矩，直接与粘度相关）

**第二步：在矩空间中松弛**

$$\mathbf{m}^* = \mathbf{m} - \mathbf{S}(\mathbf{m} - \mathbf{m}^{eq})$$

松弛矩阵 $\mathbf{S} = \text{diag}(s_0, s_1, \ldots, s_8)$，各分量的松弛率如下：

| 分量 | 对应矩 | 松弛率 |
|------|--------|--------|
| $s_0$ | 密度 ρ | 1.0（守恒，不松弛） |
| $s_1, s_2$ | 能量矩 | 1.4（可调，影响稳定性） |
| $s_3, s_5$ | 动量 | 1.0（守恒） |
| $s_4, s_6$ | 能量流 | 1.2 |
| $s_7, s_8$ | 应力矩 $p_{xx}, p_{xy}$ | ω（与粘度直接相关） |

**第三步：反投影回速度空间**

$$\mathbf{f}^* = \mathbf{M}^{-1} \mathbf{m}^*$$

MRT 平衡矩 $\mathbf{m}^{eq}$ 的 D2Q9 表达式（$|u|^2 = u_x^2 + u_y^2$）：

$$m_0^{eq} = \rho, \quad m_1^{eq} = \rho(-2 + 3|u|^2), \quad m_2^{eq} = \rho(1 - 3|u|^2)$$
$$m_3^{eq} = \rho u_x, \quad m_4^{eq} = -\rho u_x, \quad m_5^{eq} = \rho u_y, \quad m_6^{eq} = -\rho u_y$$
$$m_7^{eq} = \rho(u_x^2 - u_y^2), \quad m_8^{eq} = \rho u_x u_y$$

**MRT 相比 BGK 的优势：**
- 非物理矩（能量矩、能量流矩）可以使用更大的松弛率（接近 2），有效抑制数值不稳定性。
- 运动粘度和体积粘度可以独立控制（$\nu \propto 1/s_7$，$\xi \propto 1/s_1$）。
- 相同雷诺数下比 BGK 可运行更低粘度的仿真。

> **注：** 当格子模型为 D3Q19/D3Q27 时，三维 MRT 矩阵尚未实现，程序自动回退到 BGK。

### 5.3 Guo 体力格式

当存在外体力（如 IBM 的 spread force）时，采用 Guo 等人（2002）提出的修正格式在碰撞阶段隐式引入体力的速度修正：

$$u_{\text{eff}} = u + \frac{\mathbf{F} \cdot \Delta t}{2\rho}$$

在计算平衡分布 $f_\alpha^{eq}$ 时使用 $u_{\text{eff}}$ 代替 u，从而自动捕获体力对平衡态的修正。**完整的逐方向 Guo 修正项**（含非守恒项 $F_a$）目前为占位实现（TODO 标注），力通过速度偏移隐式处理。

## 6. 流式迁移步骤

**源文件：** `core/src/lbm/solver.cpp`（`stream()`）

流式迁移将碰撞后的分布函数 $f_\alpha^*(\mathbf{x}, t)$ 沿各离散速度方向传播一个格子步长：

$$f_\alpha(\mathbf{x} + \mathbf{c}_\alpha \Delta t, t + \Delta t) = f_\alpha^*(\mathbf{x}, t)$$

### 6.1 "推送"实现

本项目采用**推送（push）**方案：每个源节点将其分布函数值写入目标节点的临时缓冲区：

```
对每个节点 (i, j)，方向 α：
  目标节点 (di, dj) = ((i + cx_α + nx) % nx, (j + cy_α + ny) % ny)
  f_tmp[dst * Q + α] = f[src * Q + α]
```

- 目标节点使用**周期性取模**：`(i + c + n) % n`，自动实现周期边界条件。
- 非周期边界（壁面、进出口）由后续的边界条件模块覆盖修正。
- D2Q9 支持 `collapse(2)` 双层循环的 OpenMP 并行化。

### 6.2 缓冲区交换

流式迁移完成后，将临时缓冲区 `f_tmp` 与主缓冲区 `f` 交换（`std::swap`），成本为 O(1) 的指针交换，避免大规模数据拷贝。

### 6.3 宏观量更新时机

`stream()` 末尾**立即调用** `grid_.compute_macroscopic()`，确保每步结束后宏观量（ρ、u）与分布函数保持同步。这一顺序约定保证了下一步碰撞时使用的是最新的宏观量。

## 7. 宏观量计算

**源文件：** `core/src/lbm/lattice.cpp`（`LatticeGrid::compute_macroscopic()`）

宏观密度和速度是分布函数的**零阶矩**和**一阶矩**：

$$\rho = \sum_{\alpha=0}^{Q-1} f_\alpha$$

$$\rho \mathbf{u} = \sum_{\alpha=0}^{Q-1} f_\alpha \mathbf{c}_\alpha \quad \Rightarrow \quad \mathbf{u} = \frac{1}{\rho}\sum_\alpha f_\alpha \mathbf{c}_\alpha$$

**D2Q9 具体展开：**

$$\rho = \sum_{\alpha=0}^{8} f_\alpha$$

$$\rho u_x = \sum_{\alpha=0}^{8} f_\alpha (c_\alpha)_x = f_1 - f_3 + f_5 - f_6 - f_7 + f_8$$

$$\rho u_y = \sum_{\alpha=0}^{8} f_\alpha (c_\alpha)_y = f_2 - f_4 + f_5 + f_6 - f_7 - f_8$$

实现中采用对每个方向依次累加的方式，避免显式展开，便于 D2Q9 和 D3Q19 共用一套代码框架。

**LBM 压强：** $p = \rho c_s^2 = \rho/3$（格子单位下）。

## 8. 边界条件施加

**源文件：** `core/src/lbm/boundary.cpp`（`apply_boundary_conditions()`）

边界条件在每步的**流式迁移之后**施加，修正流式迁移在边界处引入的不正确的周期性数据。

### 8.1 简单反弹（Bounce-Back）

反弹边界是 LBM 中实现无滑移壁面最简单的方法，等效于粒子在壁面处以原速度弹回：

$$f_{\bar{\alpha}}(\mathbf{x}, t+\Delta t) = f_\alpha^*(\mathbf{x}, t)$$

其中 $\bar{\alpha}$ 是方向 $\alpha$ 的反方向，由 `OPP` 查找表给出。

**实现：** 对指定面（South/North/West/East）上的所有节点，将每个方向的分布函数值替换为其反方向值：

```cpp
g.f[n * Q + a] = g.f[n * Q + OPP[a]];  // a = 1..8（跳过静止方向 0）
```

**特性：** 二阶精度，无需计算宏观量，成本极低。适用于固定壁面（西、东、南面）。

### 8.2 Zou-He 速度边界条件

Zou-He 边界条件通过质量守恒和动量守恒关系，从已知的**出射方向**分布函数和**规定速度**，推算**入射方向**的分布函数，从而在边界上精确施加指定速度，具有二阶精度。

**北面（North）速度边界（规定 $u_x = U_{lid}$，$u_y = 0$）：**

已知方向（从流体内部进入边界节点）：$f_4$（南）、$f_7$（西南）、$f_8$（东南）。

计算壁面密度（由质量守恒）：

$$\rho_w = \frac{f_0 + f_1 + f_3 + 2(f_4 + f_7 + f_8)}{1 + u_y}$$

确定未知方向分布函数：

$$f_2 = f_4 + \frac{2}{3}\rho_w u_y$$

$$f_5 = f_7 - \frac{1}{2}(f_1 - f_3) + \frac{1}{6}\rho_w u_y + \frac{1}{2}\rho_w u_x$$

$$f_6 = f_8 + \frac{1}{2}(f_1 - f_3) + \frac{1}{6}\rho_w u_y - \frac{1}{2}\rho_w u_x$$

对于盖驱空腔（North 面，$u_y = 0$，$u_x = 0.1$），上式退化为速度驱动的反弹加切向动量输入。

> **参考文献：** Zou Q. & He X. (1997). *On pressure and velocity boundary conditions for the lattice Boltzmann BGK model*. Physics of Fluids, 9(6).

## 9. 浸入边界法（IBM）

**源文件：** `core/include/ibm/`、`core/src/ibm/`

IBM 用于处理浸入在流体中的**复杂移动几何体**（如柔性丝状体、圆柱），无需网格与几何体对齐。

### 9.1 拉格朗日标记点

浸入边界由一系列**拉格朗日标记点（Lagrangian Markers）** $\mathbf{X}_m$ 表示，每个标记点携带：

| 字段 | 含义 |
|------|------|
| `x, y, z` | 当前位置（物理空间） |
| `x0, y0, z0` | 参考（未变形）位置 |
| `fx, fy, fz` | 该标记点处的 IBM 力密度 |
| `ux, uy, uz` | 从流体插值得到的速度 |
| `ds` | 弧长元素（二维）/面积元素（三维） |

**生成方式（`MarkerSet` 静态工厂）：**
- `make_filament(x0, y0, length, n)`：沿 x 轴均匀分布的直线丝状体。
- `make_circle(cx, cy, radius, n)`：均匀分布的圆形标记点环。

### 9.2 δ 函数核（Delta Kernel）

IBM 的核心是通过**正则化 δ 函数**在欧拉（网格）和拉格朗日（标记点）坐标之间传递信息。

一维 δ 函数核 $\phi(r/h)$ 在 `delta_phi(r, h, kernel)` 中实现：

**2 点线性核（帽形函数，支撑宽度 2h）：**

$$\phi(r) = \frac{1}{h}\begin{cases} 1 - |r/h| & |r/h| < 1 \\ 0 & \text{otherwise} \end{cases}$$

**4 点 Peskin 余弦核（支撑宽度 4h，默认选择）：**

$$\phi(r) = \frac{1}{4h}\begin{cases} 1 + \cos\left(\dfrac{\pi r}{2h}\right) & |r/h| < 2 \\ 0 & \text{otherwise} \end{cases}$$

4 点核的优点：一阶矩守恒（保证力的精确传递），更平滑，插值误差更小；代价是支撑区域更宽（需遍历 4×4=16 个邻居节点）。

**二维 δ 函数：** 采用乘积形式 $\delta_h(\mathbf{x} - \mathbf{X}) = \phi_h(x - X)\phi_h(y - Y)$。

### 9.3 速度插值

将欧拉网格上的流体速度 $\mathbf{u}(\mathbf{x})$ 插值到拉格朗日标记点 $\mathbf{X}_m$：

$$\mathbf{u}(\mathbf{X}_m) = \sum_{\mathbf{x}} \mathbf{u}(\mathbf{x}) \, \delta_h(\mathbf{x} - \mathbf{X}_m) \, \Delta x^2$$

**实现步骤（`interpolate_velocity()`）：**
1. 将标记点位置转换为格子单位：$x_m / \Delta x$。
2. 找到最近的整数格子节点 $(i_0, j_0) = \lfloor \mathbf{X}_m / \Delta x \rfloor$。
3. 遍历 $(i_0 - s, \ldots, i_0 + s+1) \times (j_0 - s, \ldots, j_0 + s+1)$（$s = 1$ 或 2，取决于核类型），越界节点跳过（非周期截断）。
4. 对每个邻居节点 $(ii, jj)$，计算权重 $\phi_x \cdot \phi_y \cdot \Delta x^2$，累加流体速度贡献。

该操作为**收集（gather）**模式，各标记点相互独立，可并行化（`omp parallel for`）。

### 9.4 力展布

将拉格朗日标记点上的 IBM 力密度 $\mathbf{F}(\mathbf{X}_m)$ 展布到欧拉网格：

$$\mathbf{f}(\mathbf{x}) = \sum_m \mathbf{F}(\mathbf{X}_m) \, \delta_h(\mathbf{x} - \mathbf{X}_m) \, \Delta S_m$$

**实现步骤（`spread_force()`）：**
1. 清零体力场 `grid.force`。
2. 遍历每个标记点，对其支撑区域内的每个邻居格子节点叠加力贡献。
3. 展布权重为 $\phi_x \cdot \phi_y \cdot \Delta S$（$\Delta S$ 为标记点弧长元素）。

该操作为**散射（scatter）**模式，存在写竞争，使用 `#pragma omp atomic` 保证线程安全。

**IBM 的物理意义：** 通过速度插值得到标记点处的流体速度，与目标速度（结构速度）的差驱动 IBM 力，使流体"跟随"固体边界运动，从而模拟无滑移边界条件。

## 10. 流固耦合（FSI）

**源文件：** `core/include/fsi/`、`core/src/fsi/`

FSI 将 LBM 流体求解器与 Euler-Bernoulli 柔性梁有限元结构求解器耦合。

### 10.1 Euler-Bernoulli 梁有限元

**结构模型（`BeamSolver`）：**

梁划分为 $n_e$ 个单元，共 $n_e + 1$ 个节点，每节点有 3 个自由度：

$$\{d_i\} = [x_i,\; y_i,\; \theta_i]^T$$

其中 $x_i, y_i$ 为位置，$\theta_i$ 为截面转角。

**材料参数：**
- $E$（杨氏模量）、$I$（截面惯性矩）：$EI$ 为弯曲刚度
- $\rho_s, A$：结构密度和截面面积，决定质量分布
- 不可伸长梁假设：不组装轴向刚度（EA 项省略）

**单元弯曲刚度矩阵（4×4 Hermite 梁单元）：**

$$K_e = \frac{EI}{l^3}\begin{bmatrix} 12 & 6l & -12 & 6l \\ 6l & 4l^2 & -6l & 2l^2 \\ -12 & -6l & 12 & -6l \\ 6l & 2l^2 & -6l & 4l^2 \end{bmatrix}$$

自由度顺序为 $[y_i, \theta_i, y_j, \theta_j]$。

**集中质量矩阵：** $m_{\text{node}} = \rho_s A l_e$，每节点平动质量和转动惯量均匀分配（对角集中质量）。

### 10.2 Newmark-β 时间积分

结构动力学方程：$M\ddot{d} + Kd = F$

采用平均加速度法（$\beta = 1/4$，$\gamma = 1/2$），**无条件稳定**：

**预测位移：**
$$d_{\text{pred}} = d_n + \Delta t \, v_n + \Delta t^2 (0.5 - \beta) a_n$$

**有效刚度矩阵：**
$$K_{\text{eff}} = K + \frac{M}{\beta \Delta t^2}$$

**有效右端项：**
$$r_{\text{eff}} = F_{n+1} + \frac{M}{\beta \Delta t^2} d_{\text{pred}}$$

**求解：** $K_{\text{eff}} d_{n+1} = r_{\text{eff}}$（带部分主元的密集 Gauss 消元）

**更新加速度和速度：**
$$a_{n+1} = \frac{d_{n+1} - d_{\text{pred}}}{\beta \Delta t^2}$$

$$v_{n+1} = v_n + \Delta t\left[(1 - \gamma) a_n + \gamma a_{n+1}\right]$$

> **注意：** 上一步加速度 $a_n$ 当前简化为 0，对缓慢变化的流固耦合问题足够精确；对高频振动问题可通过显式存储 $a_n$ 改进。

边界约束通过矩阵奇异处理（主元接近零时将对应位移置零）施加，实现梁根部的固定边界。

### 10.3 分区显式耦合步骤

`fsi_step()` 实现单步 FSI 耦合（每次 LBM 步结束后调用）：

```
对 iter = 0..sub_iterations：
  1. 在 IBM 标记点处插值流体速度 u_IBM
  2. 计算直接力：F_IBM = κ * (v_structure - u_IBM)
     其中 κ = 1/dt（惩罚刚度）
  3. 将 IBM 力展布回欧拉网格
4. 将 IBM 反作用力（-F_IBM * ΔS）累加到最近梁节点
5. 推进梁求解器一步 (Newmark-β)
6. 将梁节点位置同步到 IBM 标记点（线性插值）
```

**直接力法（Direct Forcing）：** IBM 力使标记点处的流体速度强制趋近于结构速度，等效于在界面上施加无滑移条件。

**标记点到梁节点的映射：** 通过线性搜索找到最近梁节点（小型梁足够精确）；标记点位置由梁节点线性形函数插值更新，参考坐标 $\xi \in [0, 1]$，单元内局部坐标 $t \in [0, 1]$。

## 11. 插件扩展点

**源文件：** `core/include/plugins/`、`core/src/plugins/plugin_registry.cpp`

程序提供 4 个扩展点，可在不修改核心代码的情况下注入自定义行为：

| 扩展点 | 调用时机 | 典型用途 |
|--------|----------|----------|
| `IBoundaryPlugin::apply()` | 每步标准边界条件后 | 对流出口、开放压力、NRBC |
| `IMeshPlugin::adapt()` | 每步流式迁移后 | 自适应细化、拉伸网格 |
| `IMotionPlugin::update()` | 每步碰撞前 | 运动壁面、6 自由度刚体、ALE |
| `IFlexibleSolverPlugin::step()` | 每步流式迁移后 | Kirchhoff 板、协转梁 |

插件通过 C 函数指针（`lbm_boundary_fn` 等）注册，允许 Rust 侧通过 `lbm_bindings::register_plugins()` 安全注册。

### 插件与内置 BC / 运动 / 网格的区别

TOML `[[fluid.boundary_conditions]]` 能满足大多数**固定静态**边界（Zou-He 速度、Zou-He 压力、全反弹），这些场景**不需要**插件。当遇到以下**内置 BC 无法处理**的需求时，才需要使用插件：

| 场景 | 原因无法用内置 BC 处理 | 对应插件 |
|------|----------------------|---------|
| 对流出口（Convective Outlet）| 需要每步读取相邻内部节点速度动态计算 BC | `IBoundaryPlugin` |
| 海绵层（Sponge Layer）吸收边界 | 需要在域内施加空间分布的阻尼力 | `IBoundaryPlugin` |
| 运动壁面（正弦振荡盖板）| 边界速度每步变化，需 C++ 函数在碰撞**前**更新 | `IMotionPlugin` |
| 6 自由度刚体运动 | 需要求解运动方程后更新几何位置 | `IMotionPlugin` |
| 任意拉格朗日-欧拉（ALE） | 计算节点坐标更新及对应分布函数插值 | `IMeshPlugin` |
| Kirchhoff 板 / 协转梁 | 需替换内置 Euler-Bernoulli BeamSolver | `IFlexibleSolverPlugin` |

**总结**：内置 BC 提供零代码配置，适用于方腔、管道等经典基准；插件提供可编程扩展点，适用于非标准边界条件、运动几何体和高级结构模型。两者互不排斥，可同时激活。

### 12.1 NPZ 快照文件（`format = "npz"`，默认）

每隔 `write_interval` 步将完整欧拉场写出为 NumPy `.npz` 格式：

**文件命名：** `<output_dir>/fluid_<NNNNNN>.npz`（6 位零填充步号）

**归档内容：**

## 14. Rust ↔ C++ 跨语言调用链

程序的语言边界如下：

```
Rust (orchestrator)
  │  调用 LbmGrid::new()  →  bindings/src/lib.rs
  │                            └─ unsafe ffi::lbm_grid_new()
  │                                 └─ extern "C" lbm_grid_new()  →  core/src/capi/lbm_capi.cpp
  │                                      └─ new lbm::LatticeGrid()  →  core/src/lbm/lattice.cpp
  │
  │  调用 LbmSolver::step()  →  bindings/src/lib.rs
  │                               └─ unsafe ffi::lbm_solver_step()
  │                                    └─ extern "C" lbm_solver_step()  →  lbm_capi.cpp
  │                                         ├─ PluginRegistry::update_motion()
  │                                         ├─ Solver::step()  →  solver.cpp
  │                                         │   ├─ collide_bgk() 或 collide_mrt()
  │                                         │   └─ stream() + compute_macroscopic()
  │                                         ├─ apply_boundary_conditions()  →  boundary.cpp
  │                                         ├─ PluginRegistry::adapt_mesh()
  │                                         └─ PluginRegistry::step_flexible()
  │
  │  调用 grid.rho(idx) / ux(idx) / uy(idx)  →  通过 C ABI 读取 C++ 侧的向量元素
  │
  └─ output::write_snapshot_npz()  →  纯 Rust 实现，无需 C++ 参与
```

**C ABI 设计要点：**
- 使用不透明指针句柄（`LatticeGridHandle`、`SolverHandle`），避免 Rust 直接接触 C++ 内存布局。
- `new (std::nothrow)` 在内存不足时返回 `nullptr` 而非抛出异常，Rust 侧 `assert!(!ptr.is_null())` 转换为 panic。
- 所有跨语言数值传递均通过值语义（`int`, `double`），无共享引用，内存安全性由 C ABI 边界保证。

│  │  └─ 模式 BGK：f_α* = f_α - ω(f_α - f_eq(ρ,u))
│  │     模式 MRT：
│  │       m = M·f          (投影到矩空间)
│  │       m* = m - S(m - m_eq)  (各阶矩独立松弛)

│  │

│  │
│  ├─ [C++] apply_boundary_conditions()

│  │  └─ ZouHe_Velocity（North）：
│  │      ρ_w = (f₀+f₁+f₃+2(f₄+f₇+f₈))/(1+u_y)
│  │      f₂, f₅, f₆ 由质量/动量守恒计算
│  │
│  ├─ [C++] PluginRegistry::adapt_mesh()（网格插件，若注册）
│  ├─ [C++] PluginRegistry::step_flexible()（FSI 插件，若注册）
│  │         fsi_step():
│  │           interpolate_velocity: u_IB = Σ u(x) φ(x-X) Δx²
│  │           F_IBM = κ(v_struct - u_IB)
│  │           spread_force: f(x) += F_IBM φ(x-X) ΔS
│  │           beam.step(dt): Newmark-β 求解 K_eff d = r_eff
│  │           sync_markers_from_beam: X_m ← 梁节点线性插值
│  │
│  ├─ [Rust] 每 write_interval 步：output::write_snapshot_npz()
│  │   ├─ 遍历所有节点读取 rho[i], ux[i], uy[i]（C ABI 调用）

│  └─ [Rust] 每步（若启用）：output::append_monitor_csv()

├─ [Rust] 执行 post_script（若配置，子进程模式）
│         plot_solver_output.py：读取 NPZ → 生成 6 张流场图
└─ 程序退出

## 附录：关键算法公式速查

### LBM 核心公式

$$f_\alpha^{eq} = w_\alpha \rho \left(1 + \frac{\mathbf{c}_\alpha \cdot \mathbf{u}}{c_s^2} + \frac{(\mathbf{c}_\alpha \cdot \mathbf{u})^2}{2c_s^4} - \frac{|\mathbf{u}|^2}{2c_s^2}\right), \quad c_s^2 = \frac{1}{3}$$

$$\text{BGK:} \quad f_\alpha^* = f_\alpha - \omega(f_\alpha - f_\alpha^{eq})$$

$$\text{MRT:} \quad \mathbf{f}^* = \mathbf{f} - \mathbf{M}^{-1}\mathbf{S}(\mathbf{M}\mathbf{f} - \mathbf{m}^{eq})$$

$$\text{流式迁移:} \quad f_\alpha(\mathbf{x} + \mathbf{c}_\alpha, t+1) = f_\alpha^*(\mathbf{x}, t)$$

$$\rho = \sum_\alpha f_\alpha, \quad \rho\mathbf{u} = \sum_\alpha f_\alpha \mathbf{c}_\alpha, \quad p = \rho c_s^2$$

$$\nu = c_s^2\left(\frac{1}{\omega} - \frac{1}{2}\right) = \frac{1}{3}\left(\frac{1}{\omega} - \frac{1}{2}\right), \quad \omega = \frac{1}{3\nu + \frac{1}{2}}$$

### IBM 核心公式

$$\mathbf{u}(\mathbf{X}) = \sum_\mathbf{x} \mathbf{u}(\mathbf{x}) \, \delta_h(\mathbf{x} - \mathbf{X}) \, \Delta x^2$$

$$\mathbf{f}(\mathbf{x}) = \sum_m \mathbf{F}(\mathbf{X}_m) \, \delta_h(\mathbf{x} - \mathbf{X}_m) \, \Delta S_m$$

$$\text{Peskin 4点核:} \quad \phi(r) = \frac{1}{4h}\left(1 + \cos\frac{\pi r}{2h}\right), \quad |r| < 2h$$

### FSI 核心公式

$$\text{Newmark-}\beta: \quad K_{\text{eff}} d_{n+1} = F + \frac{M}{\beta\Delta t^2}\left(d_n + \Delta t v_n + \Delta t^2(0.5-\beta)a_n\right)$$

$$\text{直接力法:} \quad \mathbf{F}_{IBM} = \kappa(\mathbf{v}_s - \mathbf{u}_{IBM}), \quad \kappa = 1/\Delta t$$
