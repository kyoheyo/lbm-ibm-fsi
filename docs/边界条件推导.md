> **适用范围**：二维 D2Q9 格子 Boltzmann 方法  
> **参考文献**：见各节末尾引用

## 一、D2Q9 方向约定

```
D2Q9 方向编号与速度向量 c_a：

   6   2   5
    ↖  ↑  ↗
  3 ← 0 → 1
    ↙  ↓  ↘
   7   4   8

方向  编号  cx  cy  权重 w_a
静止   0    0   0   4/9
E      1   +1   0   1/9
N      2    0  +1   1/9
W      3   -1   0   1/9
S      4    0  -1   1/9
NE     5   +1  +1   1/36
NW     6   -1  +1   1/36
SW     7   -1  -1   1/36
SE     8   +1  -1   1/36

对立方向：OPP[a] = 0→0, 1→3, 2→4, 3→1, 4→2, 5→7, 6→8, 7→5, 8→6
```

**平衡分布函数**（Maxwell-Boltzmann 低 Ma 展开，格子声速 cs² = 1/3）：

$$
f_a^{eq}(\rho, \mathbf{u}) = w_a \rho \left[1 + \frac{\mathbf{c}_a \cdot \mathbf{u}}{c_s^2} + \frac{(\mathbf{c}_a \cdot \mathbf{u})^2}{2c_s^4} - \frac{|\mathbf{u}|^2}{2c_s^2}\right]
$$

**BGK 碰撞算子**（松弛时间 τ = 1/ω）：

$$
f_a^* = f_a - \omega\left(f_a - f_a^{eq}\right)
$$

**流式迁移**（push 方案，周期延拓）后，各面存在由周期延拓引入的幽灵方向（未知值），需由边界条件覆盖。

**各面幽灵方向**：

| 面 | 幽灵（未知）方向 | 已知方向 |
|----|-----------------|---------|
| 南壁 j=0    | N(2), NE(5), NW(6) | S(4), SW(7), SE(8), E(1), W(3), 0 |
| 北壁 j=ny-1 | S(4), SW(7), SE(8) | N(2), NE(5), NW(6), E(1), W(3), 0 |
| 西壁 i=0    | E(1), NE(5), SE(8) | W(3), NW(6), SW(7), N(2), S(4), 0 |
| 东壁 i=nx-1 | W(3), NW(6), SW(7) | E(1), NE(5), SE(8), N(2), S(4), 0 |

## 二、半步长反弹格式（Halfway Bounce-Back）

**物理模型**：壁面位于流体节点与虚固体节点之间半格处，精度为 2 阶。

**数学推导**：

设壁面节点 $\mathbf{x}_w$，在 $t$ 时刻碰撞后、迁移前，分布函数记为 $f^*_a(\mathbf{x}_w, t)$（保存于 `g.f_tmp`，通过 `stream()` 末尾的 `swap` 保留）。

粒子在半格处碰壁后原路返回，时序延迟恰好自然抵消：

$$
\boxed{f_{\bar{a}}(\mathbf{x}_w, t+\Delta t) = f^*_a(\mathbf{x}_w, t)}
$$

其中 $\bar{a} = \text{OPP}[a]$ 为方向 $a$ 的反向。

**各面赋值**（读取 `g.f_tmp` 中壁面节点自身的值）：

| 面 | 赋值关系 |
|----|--------|
| 南壁 j=0    | f[2]←f_tmp[4], f[5]←f_tmp[7], f[6]←f_tmp[8] |
| 北壁 j=ny-1 | f[4]←f_tmp[2], f[7]←f_tmp[5], f[8]←f_tmp[6] |
| 西壁 i=0    | f[1]←f_tmp[3], f[5]←f_tmp[7], f[8]←f_tmp[6] |
| 东壁 i=nx-1 | f[3]←f_tmp[1], f[6]←f_tmp[8], f[7]←f_tmp[5] |

> **关键点**：必须读取 `g.f_tmp`（碰后迁移前），而非 `g.f`（迁移后）。  
> 迁移后 `g.f[opp(a)]` 来自邻居内部节点，不是壁面节点自身，物理意义不同。

## 三、全步长反弹格式（Full-Way / On-Node Bounce-Back）

**物理模型**：壁面位于格子节点处，精度为 1 阶。

**数学推导**：

迁移后，壁面节点收到来自流体侧的入射分布 $f_a(\mathbf{x}_w, t+\Delta t)$（已知），粒子在节点处被立即原路反弹：

$$
\boxed{f_{\bar{a}}(\mathbf{x}_w, t+\Delta t) = f_a(\mathbf{x}_w, t+\Delta t)}
$$

**各面赋值**（读取 `g.f` 中迁移后的当前值）：

| 面 | 赋值关系 |
|----|--------|
| 南壁 j=0    | f[2]←f[4], f[5]←f[7], f[6]←f[8] |
| 北壁 j=ny-1 | f[4]←f[2], f[7]←f[5], f[8]←f[6] |
| 西壁 i=0    | f[1]←f[3], f[5]←f[7], f[8]←f[6] |
| 东壁 i=nx-1 | f[3]←f[1], f[6]←f[8], f[7]←f[5] |

> **注意**：实现时须先暂存入射方向值，再写入反射方向，避免读写混用已被修改的值。

**与半步长的比较**：

| 特性 | 半步长 | 全步长 |
|------|--------|--------|
| 壁面位置 | 节点间半格 | 节点处 |
| 精度阶次 | 2 阶 | 1 阶 |
| 来源缓冲 | `g.f_tmp`（t 时刻） | `g.f`（t+dt 时刻） |
| 适用场景 | 一般无滑移壁 | 简单几何、初学/验证 |

## 四、周期性边界条件（Periodic Boundary Condition）

**物理模型**：计算域在某方向上无限重复，等价于将出口与入口直接连接。

**实现**：在流式迁移（push 方案）中，源节点坐标取模（`% nx` 或 `% ny`）：

```
i_src = (i - C[a][0] + nx) % nx
j_src = (j - C[a][1] + ny) % ny
```

**代码**：完全隐式于 `Solver::stream()` 中，无需显式 BC 函数。`BCType::Periodic` 枚举仅作文档标注。

---

## 五、充分发展出口 / 自由出口边界（Fully-Developed / Free Outlet）

**物理模型**：在出口处假设流动沿法向（流动方向）充分发展，即法向梯度为零（Neumann 条件）：

$$
\frac{\partial f_a}{\partial n}\bigg|_{\text{outlet}} = 0 \quad \Longrightarrow \quad f_a(\mathbf{x}_{\text{out}}) = f_a(\mathbf{x}_{\text{out}} - \hat{n})
$$

其中 $\hat{n}$ 为向出口方向移动一个格子步长。

**各面赋值**（流式迁移后）：

| 面 | 赋值关系 |
|----|--------|
| East 出口（i=nx-1）  | $f_a(nx-1, j) = f_a(nx-2, j)$ |
| West 出口（i=0）     | $f_a(0, j) = f_a(1, j)$ |
| North 出口（j=ny-1） | $f_a(i, ny-1) = f_a(i, ny-2)$ |
| South 出口（j=0）    | $f_a(i, 0) = f_a(i, 1)$ |

对全部 9 个方向（$a=0,\ldots,8$）执行拷贝。

> **适用场景**：管道/通道流出口，流动在出口处已充分发展。宏观量由 `compute_macroscopic()` 自行计算，无需额外规定。

## 六、Zou-He 速度边界条件（非平衡反弹格式）

**参考文献**：Zou Q, He X. "On pressure and velocity boundary conditions for the lattice Boltzmann BGK model." Phys. Fluids, 9(6):1591–1598, 1997.

### 6.1 方法简介

Zou-He 方法利用三个宏观守恒约束（质量 + 两个动量分量）与非平衡反弹（NEBB）条件，共四个方程，求解三个未知分布函数方向。

**非平衡反弹（NEBB）条件**：对于法向与切向方向，未知方向的非平衡部分等于其对立方向非平衡部分的相反数：

$$
f_{\bar{a}} - f_{\bar{a}}^{eq} = -\left(f_a - f_a^{eq}\right)
\quad \Longrightarrow \quad f_{\bar{a}} = f_a + \left(f_{\bar{a}}^{eq} - f_a^{eq}\right)
$$

### 6.2 各面完整推导

#### 6.2.1 南壁（j=0）——规定速度 $(u_x, u_y)$

**已知方向（来自 j=1 内部）**：f[4](S), f[7](SW), f[8](SE), f[0], f[1], f[3]  
**未知方向（幽灵值）**：f[2](N), f[5](NE), f[6](NW)

**步骤一**：由质量与 y 动量约束求 ρ：
$$
\rho = \frac{f_0 + f_1 + f_3 + 2(f_4 + f_7 + f_8)}{1 - u_y}
$$

**步骤二**：用 NEBB 求法向未知方向：
$$
f_2 = f_4 + \frac{2}{3}\rho u_y
$$

**步骤三**：利用 x、y 动量方程的联立求对角未知方向。由 $f_5 + f_6 = f_7 + f_8 + \frac{1}{3}\rho u_y$（A）和 x 动量 $\rho u_x = f_1+f_5+f_8 - f_3-f_6-f_7$ 推出 $f_5 - f_6$（B），联立得：

$$
f_5 = f_7 - \frac{1}{2}(f_1-f_3) + \frac{1}{6}\rho u_y + \frac{1}{2}\rho u_x
$$

$$
f_6 = f_8 + \frac{1}{2}(f_1-f_3) + \frac{1}{6}\rho u_y - \frac{1}{2}\rho u_x
$$

#### 6.2.2 北壁（j=ny-1）——规定速度 $(u_x, u_y)$

**已知方向（来自 j=ny-2）**：f[2](N), f[5](NE), f[6](NW), f[0], f[1], f[3]  
**未知方向（幽灵值）**：f[4](S), f[7](SW), f[8](SE)

$$
\rho = \frac{f_0 + f_1 + f_3 + 2(f_2 + f_5 + f_6)}{1 + u_y}
$$

$$
f_4 = f_2 - \frac{2}{3}\rho u_y
$$

$$
f_7 = f_5 + \frac{1}{2}(f_1-f_3) - \frac{1}{6}\rho u_y - \frac{1}{2}\rho u_x
$$

$$
f_8 = f_6 - \frac{1}{2}(f_1-f_3) - \frac{1}{6}\rho u_y + \frac{1}{2}\rho u_x
$$

#### 6.2.3 西壁（i=0）——规定速度 $(u_x, u_y)$

**已知方向（来自 i=1）**：f[3](W), f[6](NW), f[7](SW), f[0], f[2], f[4]  
**未知方向（幽灵值）**：f[1](E), f[5](NE), f[8](SE)

$$
\rho = \frac{f_0 + f_2 + f_4 + 2(f_3 + f_6 + f_7)}{1 - u_x}
$$

$$
f_1 = f_3 + \frac{2}{3}\rho u_x
$$

$$
f_5 = f_7 - \frac{1}{2}(f_2-f_4) + \frac{1}{6}\rho u_x + \frac{1}{2}\rho u_y
$$

$$
f_8 = f_6 + \frac{1}{2}(f_2-f_4) + \frac{1}{6}\rho u_x - \frac{1}{2}\rho u_y
$$

#### 6.2.4 东壁（i=nx-1）——规定速度 $(u_x, u_y)$

**已知方向（来自 i=nx-2）**：f[1](E), f[5](NE), f[8](SE), f[0], f[2], f[4]  
**未知方向（幽灵值）**：f[3](W), f[6](NW), f[7](SW)

$$
\rho = \frac{f_0 + f_2 + f_4 + 2(f_1 + f_5 + f_8)}{1 + u_x}
$$

$$
f_3 = f_1 - \frac{2}{3}\rho u_x
$$

$$
f_6 = f_8 - \frac{1}{2}(f_2-f_4) - \frac{1}{6}\rho u_x + \frac{1}{2}\rho u_y
$$

$$
f_7 = f_5 + \frac{1}{2}(f_2-f_4) - \frac{1}{6}\rho u_x - \frac{1}{2}\rho u_y
$$

> **⚠️ 注意**：东壁 f[6], f[7] 中 $(f_2-f_4)$ 前的符号与西壁**相反**，源于 $u_x$ 方向相反。此处符号已经过严格推导验证，勿随意修改。

## 七、Zou-He 压力边界条件（规定密度）

**参考文献**：同 §六。

**方法**：规定壁面密度 $\rho_b$（对应压力 $p = \rho_b c_s^2$），利用宏观约束推导壁面法向速度，切向速度通常假设为零（或由 `bc.ux` / `bc.uy` 指定）。

### 7.1 各面推导

**东壁（i=nx-1）——规定密度 $\rho_b$，切向速度 $u_y = 0$（背压出口）**：

$$
u_x = -1 + \frac{f_0 + f_2 + f_4 + 2(f_1 + f_5 + f_8)}{\rho_b}
$$

$$
f_3 = f_1 - \frac{2}{3}\rho_b u_x, \quad
f_6 = f_8 - \frac{1}{2}(f_2-f_4) - \frac{1}{6}\rho_b u_x, \quad
f_7 = f_5 + \frac{1}{2}(f_2-f_4) - \frac{1}{6}\rho_b u_x
$$

**西壁（i=0）——规定密度 $\rho_b$，切向速度 $u_y = 0$（进口压力）**：

$$
u_x = 1 - \frac{f_0 + f_2 + f_4 + 2(f_3 + f_6 + f_7)}{\rho_b}
$$

$$
f_1 = f_3 + \frac{2}{3}\rho_b u_x, \quad
f_5 = f_7 - \frac{1}{2}(f_2-f_4) + \frac{1}{6}\rho_b u_x, \quad
f_8 = f_6 + \frac{1}{2}(f_2-f_4) + \frac{1}{6}\rho_b u_x
$$

**北壁（j=ny-1）——规定密度 $\rho_b$，切向速度 $u_x = 0$**：

$$
u_y = -1 + \frac{f_0 + f_1 + f_3 + 2(f_2 + f_5 + f_6)}{\rho_b}
$$

$$
f_4 = f_2 - \frac{2}{3}\rho_b u_y, \quad
f_7 = f_5 + \frac{1}{2}(f_1-f_3) - \frac{1}{6}\rho_b u_y, \quad
f_8 = f_6 - \frac{1}{2}(f_1-f_3) - \frac{1}{6}\rho_b u_y
$$

**南壁（j=0）——规定密度 $\rho_b$，切向速度 $u_x = 0$**：

$$
u_y = 1 - \frac{f_0 + f_1 + f_3 + 2(f_4 + f_7 + f_8)}{\rho_b}
$$

$$
f_2 = f_4 + \frac{2}{3}\rho_b u_y, \quad
f_5 = f_7 - \frac{1}{2}(f_1-f_3) + \frac{1}{6}\rho_b u_y, \quad
f_6 = f_8 + \frac{1}{2}(f_1-f_3) + \frac{1}{6}\rho_b u_y
$$

> **典型应用**：管道/通道流中，West 面用 Zou-He 压力（规定进口压力 $\rho_{in} > 1$），East 面用 Zou-He 压力（规定出口背压 $\rho_{out} = 1$），驱动压差驱动的流动。

## 八、郭照立非平衡外推格式（Guo 2002）

**参考文献**：Guo Z, Zheng C, Shi B. "Non-equilibrium extrapolation method for velocity and pressure boundary conditions in the lattice Boltzmann method." Chinese Physics, 11(4):366–374, 2002.

### 8.1 基本思想

将边界节点 $\mathbf{x}_b$ 的分布函数分解为**平衡部分**与**非平衡部分**之和：

$$
f_a(\mathbf{x}_b) = f_a^{eq}(\rho_b, \mathbf{u}_b) + f_a^{neq}(\mathbf{x}_b)
$$

非平衡部分由最近邻内部节点 $\mathbf{x}_f$（即 $\mathbf{x}_b$ 沿流体侧移动一个格子）外推：

$$
f_a^{neq}(\mathbf{x}_b) \approx f_a^{neq}(\mathbf{x}_f) = f_a(\mathbf{x}_f) - f_a^{eq}(\rho_f, \mathbf{u}_f)
$$

因此：

$$
\boxed{f_a(\mathbf{x}_b) = f_a^{eq}(\rho_b, \mathbf{u}_b) + \left[f_a(\mathbf{x}_f) - f_a^{eq}(\rho_f, \mathbf{u}_f)\right]}
$$

其中 $\rho_b$、$\mathbf{u}_b$ 由边界条件规定，$\rho_f$、$\mathbf{u}_f$ 为内部邻居节点的宏观量。

**此公式对全部 9 个方向 $a=0,\ldots,8$ 均成立**，相比 Zou-He 方法无需区分已知/未知方向。

### 8.2 速度边界（规定 $\mathbf{u}_b$）

1. 规定 $\mathbf{u}_b = (u_x^{bc}, u_y^{bc})$。
2. 由内部邻居近似 $\rho_b \approx \rho(\mathbf{x}_f)$（一阶近似）。
3. 对全部 9 个方向按上式赋值。
4. 更新 $\rho[\mathbf{x}_b] = \rho_b$，$\mathbf{u}[\mathbf{x}_b] = \mathbf{u}_b$。

### 8.3 压力边界（规定 $\rho_b$）

1. 规定 $\rho_b$。
2. 由内部邻居近似 $\mathbf{u}_b \approx \mathbf{u}(\mathbf{x}_f)$（一阶近似）。若指定非零 `bc.ux` / `bc.uy` 则直接使用。
3. 对全部 9 个方向按上式赋值。
4. 更新 $\rho[\mathbf{x}_b] = \rho_b$，$\mathbf{u}[\mathbf{x}_b] = \mathbf{u}_b$。

### 8.4 与 Zou-He 的比较

| 特性 | Zou-He | Guo 2002 |
|------|--------|----------|
| 精度阶次 | 2 阶 | 2 阶（名义） |
| 实现复杂度 | 中（需分面推导） | 低（统一公式） |
| 需要宏观量 | 否（自含） | 是（需预先更新 ρ, u） |
| 角点处理 | 需特殊处理 | 较自然 |
| 常用场景 | 直接施加速度/压力入出口 | 任意形状边界、浸入边界辅助 |

## 九、各边界条件使用指南

| 场景 | 推荐边界条件 |
|------|------------|
| 无滑移固壁（高精度） | 半步长反弹（`BounceBack`） |
| 无滑移固壁（简单/快速） | 全步长反弹（`BounceBackFullWay`） |
| 进口规定速度 | Zou-He 速度（`ZouHe_Velocity`）或 Guo 外推（`Guo_Extrapolation`） |
| 出口规定背压 | Zou-He 压力（`ZouHe_Pressure`） |
| 充分发展出口 | 充分发展 BC（`FullyDeveloped`）|
| 自由出口 | 自由出口 BC（`FreeOutlet`，等价于充分发展） |
| 周期性（如管道无限延伸） | 周期 BC（`Periodic`，已由流式迁移隐式处理） |
| 复杂几何入口，可指定 ρ 或 u | Guo 非平衡外推（`Guo_Extrapolation`） |

### TOML 配置示例

```toml
# 方腔流（Zou-He 速度顶盖 + 半步长反弹三壁）
[[fluid.boundary_conditions]]
bc_type = "zou_he_velocity"
face    = "north"
ux      = 0.1
uy      = 0.0

[[fluid.boundary_conditions]]
bc_type = "bounce_back"
face    = "south"

[[fluid.boundary_conditions]]
bc_type = "bounce_back"
face    = "west"

[[fluid.boundary_conditions]]
bc_type = "bounce_back"
face    = "east"

# 通道流（Zou-He 压力驱动）
[[fluid.boundary_conditions]]
bc_type = "zou_he_pressure"
face    = "west"
rho     = 1.001   # 进口高压

[[fluid.boundary_conditions]]
bc_type = "zou_he_pressure"
face    = "east"
rho     = 1.0     # 出口背压

# 通道流（Zou-He 速度入口 + 充分发展出口）
[[fluid.boundary_conditions]]
bc_type = "zou_he_velocity"
face    = "west"
ux      = 0.05
uy      = 0.0

[[fluid.boundary_conditions]]
bc_type = "fully_developed"
face    = "east"

# 使用郭照立格式作为入口 BC
[[fluid.boundary_conditions]]
bc_type = "guo_extrapolation"
face    = "west"
ux      = 0.05
uy      = 0.0
rho     = 0.0     # 0 表示用内部节点密度外推
```
